# 옷걸이 인식 센서 (담당: 서의진)

옷걸이에서 옷을 빼고 넣는 동작을 인식해 백엔드로 이벤트를 전송하는 하드웨어 모듈입니다.
실시간 AI 스타일링 제안(R-DGAACL)의 트리거 역할을 합니다.

## 동작 흐름

1. 고객이 옷걸이에서 옷을 빼면 센서가 감지
2. 센서 보드가 백엔드로 이벤트 전송 → `POST /api/devices/hanger-events`
   - payload 예시: `{ "hangerId": "H-001", "event": "PICKED_UP", "timestamp": "..." }`
3. 백엔드가 해당 행거의 상품을 조회하고 AI 스타일링 제안을 생성
4. 키오스크 화면이 결과를 표시 (폴링 또는 WebSocket/SSE)

## 센서 후보 (구매 전 비교)

| 방식 | 예시 부품 | 장점 | 단점 |
|---|---|---|---|
| 리미트/마이크로 스위치 | 행거 걸이부에 스위치 | 저렴, 단순, 오작동 적음 | 행거 개조 필요 |
| 무게(로드셀) | HX711 + 로드셀 | 걸림/빠짐 모두 정확히 감지 | 캘리브레이션 필요 |
| 적외선(IR)/근접 | IR 근접 센서 | 비접촉 | 주변광 간섭 가능 |
| RFID/NFC | RC522 + 태그 | 어떤 옷인지 식별 가능 | 태그 부착 필요, 비용 ↑ |

보드는 **ESP32** (Wi-Fi 내장, Arduino IDE 지원) 권장. 매장 Wi-Fi로 백엔드에 HTTP 전송하는 구성이 가장 단순합니다.
