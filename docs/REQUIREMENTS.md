# 요구사항 및 담당자

> ManyFast 요구사항 6건 + 팀 자체 추가 1건(하드웨어). 화면이 필요한 항목은 프론트엔드(FE) 담당을 함께 표기.

## HW-SENSOR. 옷걸이 인식 센서 (팀 자체 추가)
**담당: 서의진(하드웨어 + BE)**

옷걸이에서 옷을 빼고 넣는 동작을 인식하는 센서를 구매·프로그래밍하고, 이벤트를 백엔드로 전송합니다. 상세는 [hardware/hanger-sensor/README.md](../hardware/hanger-sensor/README.md) 참고.

- [ ] 옷 빼기/넣기 이벤트를 센서가 감지해 백엔드 API로 전송해야 한다.
- [ ] 센서 이벤트 발생 후 키오스크 화면이 해당 상품 기준으로 갱신되어야 한다.

## R-DGAACL. 실시간 AI 스타일링 제안 — 중요도 높음
**담당: 이승원(BE) / 정소민(FE) / 서의진(센서)**

사용자가 옷걸이에서 특정 옷을 선택하면, 행거 위의 스크린에서 해당 옷과 고객의 선호도를 기반으로 AI가 다양한 코디 스타일링을 실시간으로 생성하고 제시해야 합니다.
옷걸이 빼기/넣기 인식은 서의진이 별도 센서 하드웨어(`hardware/hanger-sensor`)로 구현하며, 센서 이벤트가 이 기능의 트리거가 됩니다.

- [ ] 옷이 선택된 후 3초 이내에 스크린에 최소 3가지 이상의 코디 스타일링이 제시되어야 한다.
- [ ] 제안된 스타일링은 선택된 옷과 다른 카테고리의 아이템(신발, 액세서리 등)을 포함해야 한다.
- [ ] AI 추천 정확도 지표가 80% 이상을 유지해야 한다.

## R-PXALGN. 개인화된 스타일 추천 — 중요도 높음
**담당: 전유리(BE) / 정소민(FE)**

사용자의 과거 스타일링 기록, 선호도, 체형 정보 등을 학습하여 고객 개개인에게 더욱 최적화된 맞춤형 스타일 및 아이템을 추천하는 기능을 제공해야 합니다.

- [ ] 회원 로그인 시, 기존 데이터를 기반으로 개인화된 추천 목록이 스크린에 우선 표시되어야 한다.
- [ ] 사용자가 스타일 선택 시, '좋아요' 또는 '선호하지 않음' 등의 피드백을 통해 추천 시스템을 개선할 수 있어야 한다.
- [ ] 개인화 추천을 통해 제안된 아이템의 클릭률이 비개인화 추천 대비 20% 이상 높아야 한다.

## R-QWXBTF. 직관적인 키오스크 UI/UX — 중요도 높음
**담당: 정소민(FE)**

매장 방문 고객이 쉽고 편리하게 서비스를 이용할 수 있도록 터치스크린 기반의 직관적이고 사용자 친화적인 인터페이스와 경험을 제공해야 합니다.

- [ ] 모든 기능은 3번 이하의 터치로 접근 가능해야 한다.
- [ ] 아이콘과 텍스트는 명확하고 가독성이 높아야 하며, 최소 3개 국어를 지원해야 한다.
- [ ] 사용자 테스트에서 90% 이상의 사용자가 도움 없이 기능을 성공적으로 완료할 수 있어야 한다.

## R-ZUQBEM. 스타일링 데이터 관리 및 분석 — 중요도 중간
**담당: 전유리(BE) / 김주완(FE, 대시보드)**

추천 시스템 고도화 및 매장 운영 효율성 증대를 위해 고객의 스타일링 선택, 조회 이력, 피드백 등 주요 행동 데이터를 수집, 관리, 분석하는 기능을 제공해야 합니다.

- [ ] 모든 고객의 스타일링 조회 및 선택 데이터가 실시간으로 수집 및 저장되어야 한다.
- [ ] 관리자 페이지에서 주간/월간 인기 스타일, 가장 많이 선택된 아이템 등 주요 분석 리포트를 확인할 수 있어야 한다.
- [ ] 수집된 데이터를 기반으로 AI 추천 알고리즘을 월별로 업데이트하고 성능을 개선해야 한다.

## R-UUXNUG. 관리자 페이지 — 중요도 중간
**담당: 전유리(BE) / 김주완(FE)**

상품·스타일 관리, 분석 리포트 조회 등 매장 운영을 위한 관리자 기능을 제공합니다. (ManyFast에 상세 기준 미작성 — 추후 구체화 필요)

## R-SRYMEY. 온라인-오프라인 연동 — 중요도 중간
**담당: 서의진(BE) / 김주완(FE)**

매장에서 확인한 스타일링 정보나 추천 아이템을 QR 코드로 이미지 전송 받을 수 있도록 합니다.

- [ ] 모바일 앱에서 저장된 스타일 정보는 매장 방문 시 키오스크에서 다시 불러와 볼 수 있어야 한다.
- [ ] 온라인에서 관심 상품으로 등록된 아이템의 매장 재고 여부를 키오스크에서 실시간으로 확인할 수 있어야 한다.
